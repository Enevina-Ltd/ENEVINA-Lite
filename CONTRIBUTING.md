# Contributing to Enevina Lite

Enevina Lite is a **source-available, noncommercial** project developed by
Enevina Oy. You are welcome to open issues, report bugs, and suggest hardware
and heat-pump compatibility improvements.

## Before submitting code

Enevina Oy intends to offer its own controllers and may license Enevina Lite
commercially. For that reason, accepting third-party code requires clarity
about the right to use and commercially distribute that contribution.

1. Open an issue or discussion to describe the intended contribution before
   submitting a substantial code or artwork pull request.
2. Only submit material you authored or are authorized to license. Do not
   include code, fonts, images, datasets, firmware blobs, or other material
   copied from third parties without checking and documenting its license.
3. Enevina Oy may ask contributors to sign a separate Contributor License
   Agreement (CLA) or provide an equivalent written permission covering
   commercial integration before accepting a contribution. **Submitting a PR
   alone does not transfer copyright or grant Enevina Oy commercial rights.**
4. Contributions without the required rights documentation may remain open
   for discussion but should not be merged.
5. Do not post credentials, API tokens, Wi-Fi passwords, NVS dumps, private
   signing keys, MAC-address inventories, or private test logs.

## Scope

Keep the one-heat-pump-per-device, local-first, non-AI product scope.
Firmware and hardware safety changes must follow [AGENTS.md](AGENTS.md)
and the repository's review and testing procedure. Opening a pull request
does not authorize flashing devices or writing commands to physical pumps.

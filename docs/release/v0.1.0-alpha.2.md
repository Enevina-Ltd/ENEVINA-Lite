# Enevina Lite v0.1.0-alpha.2 — Local integrations and OTA developer preview

**19 November 2026 · Source-only prerelease · Enevina Ltd (registered in Finland as Enevina Oy)**

This second developer preview continues Enevina Lite, the local-first ESP32-S3 heat-pump controller for **one heat pump per device**. It is intended for contributors and technical evaluation, not unattended heating control or general consumer installation.

## What's new since v0.1.0-alpha.1

- **Midea V2/V3 LAN read-only support:** native C++ status readers for Midea-compatible Wi-Fi devices over local TCP/6444, with an explicit V2/V3 protocol choice in the dashboard. V3 uses device-specific authentication; V2 uses a shared fixed key and is not equivalent to authenticated V3. No Midea setpoint, mode or power-control writes are enabled. Physical Lite-to-Midea compatibility is **not yet validated**, including the separately Core-tested Frezzer Nordic.
- **Firmware updates from the dashboard:** source implementation of a confirmation-driven, signed HTTPS OTA download and A/B rollback path. Test/device evidence is limited; this is **not** an approved universal end-user OTA package.
- **Safer Wi-Fi onboarding:** the intentionally passwordless setup access point is restricted to Wi-Fi provisioning. Heating control and phase-two settings are blocked from the setup-AP interface. No new login, password or PIN was introduced.
- **NVS and control authorization:** corrections for explicit user control reauthorization after signed OTA on constrained NVS storage. The existing firmware-image and pump identity checks remain in force; no automatic authorization of heating control is implied.
- **More reliable sensors and weather:** fixes to RuuviTag BLE behavior under memory pressure and MET Norway global forecast integration. Electricity-price, sensor and thermal-model interfaces remain in active development.
- **Research and collaboration:** more manufacturer/local-protocol documentation, clarified cloud-dependent V3 pairing limitations, and English/Finnish project material.

## Verification

The combined development tree passed **37/37 native CMake/CTest tests** and an **ESP32-S3 firmware build**. The Wi-Fi onboarding source regressions passed **22/22** tests. The exact tagged release commit is also verified by GitHub Actions before publishing. These are development/build results, **not** certification or complete physical model compatibility tests.

## Important limitations

- **No prebuilt, production-signed firmware or one-click installer is included.** GitHub's automatic source ZIP and tarball are the downloadable release assets.
- **Do not flash onto an unknown board, enable unattended pump control or modify live heat-pump settings on the basis of this source-only release.**
- Midea V2/V3 status reading is experimental; each module and protocol version requires separate validation. Midea V3 credentials may require manufacturer cloud during initial pairing; a locally operating connection does not prove fully cloud-free onboarding.
- Model-specific CN105 command paths and deterministic optimization remain experimental until device-specific safety and performance checks are complete.
- Source-available, **not OSI open source**. The Enevina Lite Noncommercial Community License 1.0 applies. Commercial distribution or resale requires separate written permission from Enevina Oy.

## Suomeksi

**Enevina Lite v0.1.0-alpha.2** on lähdekoodijulkaisu kehittäjille. Uutta ovat Midea V2/V3 -lämpöpumppujen paikallinen **tilanluku**, dashboardin allekirjoitetun OTA-päivityksen kokeellinen toteutus, salasanattoman Wi-Fi-asennusverkon ohjausrajoitukset ja NVS-tallennuksen korjaukset. Lisäksi RuuviTag- ja sääennustetoteutusta on kehitetty.

**Midean lämpötilan muutto- ja muut ohjauskomennot eivät kuulu tähän versioon.** Fyysinen Lite-yhteensopivuus ja tuotteen turvallisuus on varmennettava laitemallikohtaisesti. Julkaisu ei sisällä valmista asennettavaa firmwaretiedostoa eikä se anna lupaa asentaa firmwarea käytössä oleviin pumppuihin. Lisenssi sallii ei-kaupallisen käytön ehtojensa mukaisesti; kaupallinen käyttö tarvitsee Enevina Oy:n luvan.

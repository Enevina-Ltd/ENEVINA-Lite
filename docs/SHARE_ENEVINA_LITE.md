# Introducing Enevina Lite / Esittelytekstit

Use accurate, dated descriptions when sharing the repository. **Do not announce a supported heat-pump catalogue, certified firmware installer, real-world savings percentages or a finished product before independently verifying them.**

## Short introduction — English

> Enevina Lite is a source-available ESP32-S3 project exploring **local heat-pump control and 15-minute electricity-price optimization** without requiring Home Assistant or a continuous cloud connection. It combines a local dashboard, weather forecasts, manufacturer-specific adapters and deterministic thermal-model/MPC research. The first development adapter targets Mitsubishi Electric CN105; the project is still an early developer preview, not a certified plug-and-play controller. Feedback on local heat-pump protocols and reproducible tests is welcome.
>
> GitHub: https://github.com/linkki79-pixel/ENEVINA-Lite

## Lyhyt esittely — suomeksi

> Enevina Lite on ESP32-S3:lle kehitettävä paikallinen lämpöpumppuohjain, jonka tavoitteena on pörssisähkön 15 minuutin hintojen, sääennusteen ja rakennusfysiikan hyödyntäminen lämmityksen ohjauksessa. Home Assistantia tai jatkuvaa pilviyhteyttä ei tarvita suunniteltuun paikalliseen toimintaan. Ensimmäinen kokeellinen laiteadapteri on Mitsubishi Electric CN105, mutta yleinen malliyhteensopivuus ja todelliset säästöt ovat vielä todentamatta. Projekti on kehittäjien esijulkaisu; palaute ja toistettavat testit kiinnostavat.
>
> GitHub: https://github.com/linkki79-pixel/ENEVINA-Lite

## Evidence to attach when sharing

- A **real screenshot or video** of the current dashboard, labelled with firmware version and test conditions. Do not use a concept rendering as a working screenshot.
- A link to [model compatibility](COMPATIBILITY.md), including limitations.
- A reproducible host-test or simulated benchmark, clearly labelled *simulation*, not field savings.
- A clear noncommercial license note and an invitation to discuss model-specific adapters.
- A statement that the first [alpha release](https://github.com/linkki79-pixel/ENEVINA-Lite/releases/tag/v0.1.0-alpha.1) contains source code but no approved general firmware installer.

## Community etiquette

Share the project only where it is relevant and the community rules permit it. Be available for technical questions; don't cross-post identical advertising messages. Correct reported issues and make claims only to the level of their supporting evidence.
